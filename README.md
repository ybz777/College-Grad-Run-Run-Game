# JOBRUN 2026

Satirical endless runner about surviving the 2026 entry-level job market.

**No Experience Required\***  
\*Experience required.

## Play locally

```bash
npm install
npm run dev
```

Then open [http://localhost:5173/](http://localhost:5173/).

## Controls

- **A / Left** — lane left
- **D / Right** — lane right
- **W / Up / Space** — jump
- **S / Down** — slide
- **Escape** — pause
- On a phone: swipe or use the on-screen pads
